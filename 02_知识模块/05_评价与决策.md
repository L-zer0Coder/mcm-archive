# 评价与决策

> 学习核心模块之一，服务的典型场景：方案比选、指标体系、可持续性评估、政策排序——一切"多指标下排好坏"的问题。
> 验证环境：NumPy 2.5.1，Windows，2026-11-22 全部代码实跑通过。
> 赛制相关的内容在 03_题型打法，本模块只讲方法本身。

## 0. 先建地图：评价问题的四个部件

| 部件 | 内容 | 交代方式 |
|---|---|---|
| 方案集 | 被评价的对象 | 明确、互斥、穷尽讨论范围 |
| 指标集 | 衡量维度 | 来源声明（文献/数据/利益相关方） |
| 权重 | 维度间的取舍 | 主客观结合 + 一致性/稳健性检验 |
| 合成 | 折成一个分数 | 方法选择 + 敏感度 |

**心法三句**：评价方法不产生信息，它只整理信息——权重与指标才是结论的全部来源；任何单一定权方法都要被第二种方法校验；没有敏感度分析的评价排名不算结论。

## 1. 概念讲透

### 1.1 指标体系：先逆指标，再标准化

指标三问：**够不够**（覆盖评价目的）、**冗不冗**（高度相关的两个指标等于变相双倍计权）、**方向**（成本型指标要逆变换，让"越大越好"全局统一）。逆变换两种常用式：$x' = \max - x$ 或 $x' = 1/x$——**数据含 0 或负值禁用 $1/x$**（除零爆炸；且 $1/x$ 对小值差异是非线性放大，两种变换不保证同序，论文里注明用的是哪种）。标准化用极差正规化 $z_{ij} = \frac{x_{ij}-\min_j}{\max_j-\min_j}$，把所有指标拉到 $[0,1]$——不加标准化直接加权，量纲大的指标会独裁。

**冗余检查**是新手最容易跳过的一步：两个相关系数 0.9 的指标并存，权重名义上一半一半，实际上这个维度占了一半以上。处理：合并成一个综合指标，或明确说明保留理由。

### 1.2 权重三法：主观、客观、组合

- **AHP（层次分析法）**：专家两两比较（"成本比风险重要多少？"），特征向量给权重。主观、可解释，但依赖比较质量——**必须做一致性检验**（§1.4）；
- **熵权法**：某指标各方案取值越接近（熵越大），它区分方案的能力越弱，权重越小。客观、全自动，但**它度量的是"区分度"不是"重要性"**——一个真实重要但各方案表现相同的指标会被熵权压到近零；
- **组合赋权**：$w = \alpha\,w_{AHP} + (1-\alpha)\,w_{熵}$，主客观互相牵制。α 的选择本身做敏感度（0.3/0.5/0.7 各跑一遍）。

单一方法的排名若与组合法冲突，冲突本身就是论文里的分析素材。

### 1.3 合成方法：TOPSIS 与它的直觉

TOPSIS 的直觉：最优方案应该**离"理想解"（各指标取最优值）最近、离"负理想解"最远**。加权欧氏距离给两个距离，综合得分 $C_i = \frac{D_i^-}{D_i^+ + D_i^-}$ 落在 $[0,1]$。它是**补偿型**方法：某指标崩塌可能被其他指标的高分抵偿、被距离拉回前排——所以先用**劣解淘汰**设硬底线（任一硬指标不达标直接出局，再谈排名）。反向的失效也要知道：单项碾压的方案，其收益被理想解上限封顶，TOPSIS 会低估它——可补一个加权平均得分作对照，两法分歧本身就是分析素材。

### 1.4 一致性检验：CR < 0.1 的含义

两两比较可能出现"A>B, B>C, 但 C>A"的循环——逻辑不自洽。AHP 用一致性比率 CR 度量：$CR = CI/RI$，其中 $CI = (\lambda_{max}-n)/(n-1)$，RI 按矩阵阶数查表（n=3:0.58、4:0.90、5:1.12、6:1.24、7:1.32、8:1.41、9:1.45；不同文献的 RI 表略有差异，论文里注明所用版本）。**CR < 0.1 视为可接受，超出则比较矩阵需要返工**（通常是专家判断前后矛盾）。注意 CR 只检验"比较逻辑自洽"，不检验"判断正确"——它管不了专家拍脑袋拍错了方向。

### 1.5 敏感度：评价结论的最后一块砖

排名对权重敏感：把每个权重 ±20%（其余按比例归一）重算 TOPSIS，报告**排名是否翻转**。哪些指标权重一变冠军就易主，比冠军是谁更有决策价值——它指出"这次评价真正的胜负手"。

## 2. 最小可复现代码

以下两段 2026-11-22 在 NumPy 2.5.1 实跑通过，输出为真实结果。

### 2.1 熵权法 + 加权 TOPSIS（三方案三指标）

```python
import numpy as np
# 方案×指标：[得分(效益), 成本(逆指标), 风险(逆指标)]
X = np.array([[8, 3000, 4], [6, 5000, 3], [9, 2000, 5]], float)
X[:, 1] = 1 / X[:, 1]                      # 成本逆指标化（越大越好）
Z = (X - X.min(0)) / (X.max(0) - X.min(0) + 1e-12)   # 极差正规化
P = (Z + 1e-12) / (Z + 1e-12).sum(0)
E = -(P * np.log(P)).sum(0) / np.log(len(X))         # 各指标熵
w = (1 - E) / (1 - E).sum()                          # 熵权
print("熵权 =", np.round(w, 3).tolist())
Dp = np.sqrt(((Z - Z.max(0)) ** 2 * w).sum(1))       # 距理想解
Dn = np.sqrt(((Z - Z.min(0)) ** 2 * w).sum(1))       # 距负理想解
score = Dn / (Dp + Dn)
print("TOPSIS 得分 =", np.round(score, 3).tolist(), " 最佳 = 方案", int(score.argmax()) + 1)
```

真实输出：

```
熵权 = [0.311, 0.352, 0.338]
TOPSIS 得分 = [0.531, 0.0, 1.0]  最佳 = 方案 3
```

读法：熵权接近均匀（0.311/0.352/0.338）说明本数据各指标区分度差不多——**熵权法对数据量极敏感，三个方案算熵权只是演示规模，实战至少八到十个方案**。方案 3 得分 1.0、方案 2 得分 0.0：它们恰好是理想解与负理想解本身（本例只有三个方案时常见），排名的实质内容在中间方案上。**正规化选择极差法时，"最差方案"必然是 0 分，不要把 0 分解读为"一无是处"**。

### 2.2 AHP：权重与一致性检验

```python
import numpy as np
A = np.array([[1, 3, 5], [1/3, 1, 3], [1/5, 1/3, 1]])  # 两两比较矩阵
vals, vecs = np.linalg.eig(A)
lam = float(vals.real.max())
wv = np.abs(vecs[:, int(vals.real.argmax())])
wv = wv / wv.sum()
CI = (lam - 3) / 2                       # n=3，一致性指标
print("权重 =", np.round(wv, 3).tolist())
print("λmax =", round(lam, 3), " CI =", round(CI, 4),
      " CR =", round(CI / 0.58, 4))
```

真实输出：

```
权重 = [0.637, 0.258, 0.105]
λmax = 3.039  CI = 0.0193  CR = 0.0332
```

读法：权重约 64/26/10（比较矩阵里"3 倍重要、5 倍重要"的数字翻译）；CR = 0.033 < 0.1，比较逻辑自洽，权重可用。若某专家的矩阵算出 CR = 0.25，返工的是**比较矩阵**（让 TA 重新回答冲突的条目），不是硬交——这就是 §1.4 的操作含义。

## 3. 在真题中的用法

题目信息核查于 2026-11-22（来源：COMAP 官网历年题目页）。

| 真题 | 场景 | 评价范式 | 三行翻译 |
|---|---|---|---|
| 2026 ICM E《Passive Solar Shading》（被动式遮阳） | 遮阳方案多目标比选（官方题面 2026-11-22 核：夏挡冬纳、采暖制冷成本） | 方案集=设计参数组合；指标=采光/热负荷/成本；TOPSIS 或 ε-约束排序 | 变量=设计参数；目标=综合得分；检验=权重敏感度 |
| 2025 ICM E《Making Room for Agriculture》（农业空间） | 栖息地从森林到农田的演化追踪（官方题面 2026-11-22 核） | 演化主体属动力学建模（接 [02_微分方程与动力学](02_微分方程与动力学.md)）；评价方法用于生态系统成熟度指标与措施比选 | 变量=生境状态指标；权重=组合赋权；结论=成熟度评分 + 敏感度 |

两题共同的骨架：**指标来源声明（§1.1）→ 逆指标与标准化 → 劣解淘汰设硬底线 → 组合赋权（§1.2）→ 合成排名（§1.3）→ 权重敏感度（§1.5）**。评价类工作的质量几乎全押在"权重来源"与"敏感度完整性"两处——方法本身不难，纪律决定可信度。另注意题面范式别按标题臆断：2025 E 的主体是生态演化建模，评价只是收尾的评分环节，方法组合要贴着题面任务走。

## 4. 常见误用

1. **逆指标忘处理**。成本、风险直接进"越大越好"的流水线，排名整体反转——本类问题第一大事故（§2.1 第一步就是处理它）。
2. **冗余指标双计权重**。相关系数 0.9 的两个指标各占权重，该维度实质独大。先做相关性检查再定指标表（§1.1）。
3. **熵权当客观真理**。熵权度量区分度而非重要性（§1.2）；数据质量差时熵权就是垃圾进垃圾出。永远与主观法组合使用。
4. **AHP 不做一致性检验**。CR > 0.1 的权重等于承认专家逻辑混乱，必须返工比较矩阵（§2.2）。
5. **标准化方法与数据不匹配**。极差法对极端值敏感（一个离群点压缩其他所有方案的区分度）；数据有离群点时改 z-score 标准化，并在论文里说明选择理由。
6. **只给排名不给敏感度**。权重 ±20% 排名就翻转的评价，结论必须写"在权重区间 A 内方案 1 优，区间 B 内方案 2 优"——给出条件化结论而非单一冠军。
7. **方案数太少硬上熵权**。三五个方案算信息熵，权重基本是噪声（§2.1 演示的规模）。小方案集用 AHP 主导，熵权只做参考。
8. **劣解不淘汰**。任一硬指标（如安全底线）不达标的方案应先出局再排名，TOPSIS 的距离补偿可能把"单项崩塌"方案拉回前三。
