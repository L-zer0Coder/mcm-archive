# 写作与 Summary Sheet

> 学习核心模块之一，服务的对象：竞赛论文（含 Summary Sheet）、模型报告、任何"模型要给人看"的场合。本模块与官方写作要求的衔接见 [竞赛要点](../01_COMAP官方/竞赛要点.md)。
> 验证环境：Python 3.12，2026-11-22 代码实跑通过。机械修订规则的出处见 §1.4 与参考资料。
> 与赛制相关的官方要求（AI 报告格式等）以当年 Contest Instructions 为准，本模块只讲写作方法。

## 0. 先建地图：读者的阅读路径

假设评委（或导师、或任何读者）只有 15 分钟：**先读 Summary（一页）→ 扫图表 → 抽查正文一节**。写作的全部策略从这个路径倒推：

| 环节 | 读者在做什么 | 你的对策 |
|---|---|---|
| Summary 初筛 | 决定这篇值不值得细看 | 数字、方法主线、结果三件齐全 |
| 扫图表 | 用图重建你的论证 | 每图一个论点、自明 |
| 抽查正文 | 验证可信度 | 假设可追溯、公式有编号、数据有出处 |

**心法三句**：Summary 是全文压缩不是全文摘要引言；每个论点带具体数字；图表是论证的主角，正文是图表的旁白。

## 1. 概念讲透

### 1.1 Summary Sheet 配方：六要素骨架

一页 Summary 的骨架（每个要素一个职责，各 1–3 句，顺序即逻辑）：

1. **问题与目标**（1–2 句）：把题面翻译成"我们要决定/预测/评估什么"，具体到量；
2. **方法主线**（2–3 句）：模型链条一句话讲清（如"ODE 刻画放电 → 蒙特卡洛灌入使用场景不确定性 → 分位数给出续航结论"），**逻辑连接词体现模型间的输入输出关系**；
3. **关键结果**（2–3 句）：**全部带数字**（最优值、gap、P90、超限概率），这是 Summary 与平庸作文的分水岭；
4. **检验与稳健性**（1–2 句）：收敛性/样本外/敏感度各一句，证明结论不是运气；
5. **亮点或政策含义**（1 句）：模型独特之处或对决策方的直接建议；
6. （如需要）**关键词行**：方法名与题型标签。

反面自查：把 Summary 写成"首先我们……然后我们……最后我们……"的流水账，是方法堆砌而非论证——每个"我们做了 X"都要接"所以得到了 Y（数字）"。

### 1.2 数字优先原则

模糊词与数字的区别就是"效果不错"与"误差 2.1%"的区别。纪律：

- 结论句必带量：数值 + 单位 + 对照物（"比基准低 12%"而非"显著降低"）；
- 精度与样本量匹配（蒙特卡洛精度纪律见 [06_蒙特卡洛与模拟](06_蒙特卡洛与模拟.md) §1.2）；
- 每个数字在正文可追溯（编号/表格引用），Summary 里的数字与正文完全一致——**前后不一致是最致命的低级伤**。

### 1.3 图表纪律：一图一论点

- **图题写结论不写内容**："图 3：权重扰动下方案排名的变化（方案 1 在 α<0.4 时反超）"——读者只看图题就能拿到论点；
- 每图自明：坐标轴带单位、图例完整、色盲友好的配色；
- 表格用于精确数字（参数表、权重表），图用于趋势与对比——同一数据不重复又表又图；
- 图必须被正文引用（"如图 3 所示……"），没被引用的图是孤儿。

### 1.4 中式表达的机械修订与人工重写

中译英的两类问题要分开处理：**冗余结构**可以机械替换（§2 的脚本），**语态与语序**必须人工重写。高频机械修订六条（前三条出自 Strunk《The Elements of Style》的删冗余与主动语态元规则；第 6 条与 upc-archive 润色库 §6.2 呼应——该库是站外资源，见参考资料）：

| 中式写法 | 修订 | 类型 |
|---|---|---|
| In order to | To | 冗余 |
| it can be seen that | （直接删除） | 冗余 |
| the model which was proposed by us | the model we proposed | 定语从句臃肿 |
| has the ability to | can | 冗余 |
| make a comparison of A and B | compare A and B | 名词化臃肿 |
| obviously / clearly | （删除——让证据说话） | 语气滥用 |

剩下的被动语态堆叠（"the simulation was conducted by us"）机械替换治不了——需要改写为主动（"we ran the simulation"）。**机翻感的主要来源正是语态与语序，不是词汇**；词汇替换只是第一步。

### 1.5 AI 使用披露的写法

如实、结构化、可复现：系统与版本、每条原始提问、**完整输出**（COMAP AI 政策原文要求 "complete output"，2026-11-22 核对政策 PDF v102025；纯翻译用途可按政策示例只附一句声明）——格式按官方当年 Instructions 附上（要求本身见 [竞赛要点](../01_COMAP官方/竞赛要点.md)）。**写作纪律**：披露是清单不是检讨；生成后必须有人工验证与修改痕迹（结果数字、公式、图表自己重做），完全未验证的 AI 输出与未披露同样危险。

### 1.6 引用与出处

引用纪律赛制无关、一以贯之：**外部数据**（每个数据集标来源与获取日期）、**他人图表与结论**（直接引用或改绘需注明）、**AI 工具**（按 §1.5 披露并进引用列表）——凡是"不是你做的"都要能给读者指出处。图注标数据来源；正文引用与文末列表一一对应（§5 终检项）。

## 2. 最小可复现代码

写作自检的机械部分可以脚本化。以下片段 2026-11-22 在 Python 3.12 实跑通过：

```python
text = ("In order to analyze the model which was proposed by us, "
        "it can be seen that the simulation was conducted by us.")
rules = [("In order to", "To"),
         ("which was proposed by us", "we proposed"),
         ("it can be seen that ", "")]
out = text
for bad, good in rules:
    out = out.replace(bad, good)
print("修订前", len(text.split()), "词 → 机械修订后", len(out.split()), "词")
print(out)
```

真实输出：

```
修订前 22 词 → 机械修订后 12 词
To analyze the model we proposed, the simulation was conducted by us.
```

读法：机械规则砍掉 10 个冗余词（约 45%），但剩下的 "the simulation was conducted by us" 仍是被动堆叠——**机械替换的边界就在这里**，语态改写（"we ran the simulation"）需要人来重排语序。这个两段式（脚本删冗余 → 人工改语态）正是润色的正确工序。

## 3. 在实战中的用法

写作模块的"用法"贯穿全周期，以三道检查点落地：

| 阶段 | 动作 | 用本模块的哪一节 |
|---|---|---|
| 赛前 | Summary 六要素模板 + 图表规范先建模板文件（官方 Instructions 提供 Word/LaTeX Summary Sheet 模板可下载）；机械修订规则表贴在工位 | §1.1、§1.4 |
| 赛中 | 每天写一版 Summary（模型推进到哪写到哪），最后一天做的是压缩与校数字，不是从零写 | §1.2 |
| 终检 | 数字一致性全文对账（Summary ↔ 正文 ↔ 图表）；图题逐条检查"结论式图题"；AI 披露格式核对 | §1.3、§1.5 |

写作时间占全程的四分之一以上是常态（经验值，无官方统计）；**把它当模型工作的一部分（每天 1–2 小时），而不是最后一天的任务**，是写作质量的最大单一杠杆。页数预算的逐节对账工具规划在 06_赛时工具（页数预算器，待上线）。

## 4. 常见误用

1. **Summary 写成流水账**。"首先……然后……最后……"式方法罗列，无结果数字、无逻辑主线（§1.1 的六句结构逐句对照修）。
2. **结论不带数字**。"模型效果良好"不是结论；"样本外误差 3.2%，优于基准 1.8 个百分点"才是（§1.2）。
3. **Summary 与正文数字不一致**。最后一天改了正文忘了同步 Summary——终检必须做全文数字对账。
4. **图题写内容不写论点**。"图 2：各方案得分"是无效图题；结论进图题（§1.3）。
5. **被动语态堆叠**。机翻感的主要来源；机械替换治不了，要人工改主动（§1.4、§2）。
6. **术语不定义就使用**。第一次出现的符号与专有名词必须就地定义（或指向符号表）。
7. **AI 输出未验证直接采用**。数字、公式、图表逐项人工核对；披露文件是清单不是事后补写的检讨（§1.5）。
8. **格式漂移**。公式不编号、引用无出处、图表孤儿化——用终检清单逐条过（§5）。

## 5. 自检清单

- [ ] Summary 六要素齐全，结果句全部带数字
- [ ] Summary、正文、图表三处数字一致（终检对账）
- [ ] 每图一个论点，图题写结论，图被正文引用
- [ ] 坐标轴单位、图例、配色可及性检查
- [ ] 术语与符号首次出现即定义
- [ ] 机械冗余已清理，被动语态人工改写完成
- [ ] AI 使用披露：系统/提问/输出三要素齐全且与实际使用一致
- [ ] 全文经"15 分钟读者路径"自查：只读 Summary 能否复述方法与结果
