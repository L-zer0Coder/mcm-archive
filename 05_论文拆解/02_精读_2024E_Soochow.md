```python
# 审计 1：Table 4 的权重是否符合论文自述公式 eq(19)？  数据 = 论文 p.14 印刷值
# 审计 2：Table 3 的预测列是否自洽于论文 eq(11)-(12) 的 GM(1,1)？ 数据 = 论文 p.11 印刷值
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# eq(19): w_j = (1-E_j) / sum(1-E_k)   —— Table 4 打印的 E 与 w
E = np.array([0.3333, 0.4444, 0.3889, 0.2778])
w_paper = np.array([0.375, 0.250, 0.250, 0.125])
w_eq19 = (1 - E) / (1 - E).sum()
print("max |w_paper - w_eq19| =", round(float(np.abs(w_paper - w_eq19).max()), 4))
# 输出 0.1576 —— 四条全不一致；论文权重恰为 3/8, 2/8, 2/8, 1/8（手工凑整痕迹）

# eq(11)-(12): AGO + 最小二乘 + 时间响应 + 逆 AGO   —— Table 3 中国列 2024-2034
x = np.array([2453.24, 2558.72, 2660.72, 2760.77, 2864.32, 2964.62,
              3063.62, 3185.22, 3335.21, 3365.97, 3483.72])
n = len(x)
ago = np.cumsum(x)                                   # Y(1)(i) = sum X*(k), eq(11) 上式
z = (ago[:-1] + ago[1:]) / 2.0                       # 背景值（紧邻均值）
B = np.column_stack([-z, np.ones(n - 1)])            # 灰色微分方程的离散化矩阵
a, b = np.linalg.lstsq(B, x[1:], rcond=None)[0]      # (a, b)^T = (B^T B)^(-1) B^T Y_N
k = np.arange(0, n)
y1 = (x[0] - b / a) * np.exp(-a * k) + b / a         # 时间响应 eq(12)（AGO 层）
xf = np.concatenate([[y1[0]], np.diff(y1)])          # 逆累加生成还原原始层
resid = (x - xf) / x * 100
print("refit residuals (%) =", np.round(resid, 2).tolist())
# 输出 [-0.0, -0.76, -0.28, -0.03, 0.22, 0.22, 0.07, 0.52, 1.67, -0.84, -0.84]
# 前 8 年 <=0.76%（舍入可解释），2029 起出现 0.52-1.67% 的偏离

fig, axes = plt.subplots(1, 2, figsize=(11, 4.2))
xs = np.arange(4)
axes[0].bar(xs - 0.18, w_paper, 0.36, label="paper Table 4 weights")
axes[0].bar(xs + 0.18, w_eq19, 0.36, label="recomputed via eq(19)")
axes[0].set_xticks(xs, ["Healthcare", "GDP pc", "Pop.Dens", "Edu"], fontsize=9)
axes[0].legend(fontsize=8)
axes[0].set_title("weights vs eq(19): max dev 0.158", fontsize=10)
years = np.arange(2024, 2024 + n)
axes[1].plot(years, x, "o-", label="printed Table 3 values")
axes[1].plot(years, xf, "s--", label="standard GM(1,1) refit")
axes[1].legend(fontsize=8)
axes[1].set_title("refit resid: mean 0.49%, max 1.67% (2029-2034)", fontsize=10)
fig.tight_layout()
fig.savefig("audit_2024E.png", dpi=110)
```

## 3. 公式逐条精讲

### eq(5)-(6)：MGWR 主模型（p.8-9）
**怎么想到**：赔付既受气候影响又有空间异质性（西部旱、东南涝——Fig 2），普通 OLS 只能给全国一个系数，抹掉了地理差异。
**完整推导**：GWR 的一般式 $y_i = \beta_0(u_i,v_i) + \sum_k \beta_k(u_i,v_i)X_{ik} + \epsilon_i$（eq5）——每个位置 $(u_i,v_i)$ 用它周边样本拟合**自己的**系数，权重随距离衰减（高斯核：$w_{ij}=\exp(-d_{ij}^2/b^2)$，带宽 $b$ 控制邻域大小）。MGWR 的增量（eq6 的应用形态）：$\mathcal{I}_i = \beta_0(u_i,v_i) + \sum_{k=1}^{4}\beta_k(u_i,v_i)\,PCA^{k}_{Factor} + \beta_5(u_i,v_i)\,\mathcal{P}_i + \epsilon_i$——论文比 GWR 多说的一句话是"每个协变量各自有带宽"：气候因子的影响尺度可能与人口密度不同，硬用同一个带宽会把快变量抹平。带idge估计：对每个 $\beta_k$ 独立做带宽搜索（论文未述核函数与搜索细节——这是它"无诊断表"缺项的来源之一）。
**适用边界**：需要足够密的空间样本；外推到样本稀疏区（如 Q3 单个地标）时，MGWR 退化为"系数区间解读"（p.20-21 的区间表述正是承认了这一点）。

### eq(7)-(9)：定价链（p.9）
**怎么想到**：题面要"既人道又盈利"的定价——把两个价值各参数化，再乘法合成。
**完整推导**：人文系数 $H_i = g(SEF_i)$（eq7，g 由熵权综合指数线性化而来，见 eq21）；盈利因子 $P = HPR + TPM$（eq8，历史赔付率+目标利润率）；最终 $FP_i = BP \times (1+\theta\,RS_i) \times H_i \times P$（eq9）——风险分 $RS_i$ 抬价、人文系数 $H_i$ 让利、盈利因子兜底。
**适用边界**：乘法合成意味着任何一项趋零则保费趋零——$H_i$ 必须有下界（论文未讨论，普通队补一个 clamp 是低成本加分）。

### eq(11)-(12)：GM(1,1)（p.10）
**怎么想到**：只有 11 个年度点、且要外推 11 年——样本量不允许 ARIMA，灰色模型专为"少数据、指数型趋势"设计。
**完整推导**：① AGO 平滑：$Y^{(1)}(i)=\sum_{k=1}^{i}X^{*}(k)$——累加把震荡抹成近似指数曲线；② 灰色微分方程 $\frac{dY^{(1)}}{dt} + aY^{(1)} = b$；③ 离散化最小二乘：对 $k=2..n$ 用背景值 $z(k)=\frac{1}{2}(Y^{(1)}(k)+Y^{(1)}(k-1))$ 代替导数点，得矩阵形式 $[a,b]^T=(B^TB)^{-1}B^TY_N$（eq11，$B$ 的每行 $[-z(k), 1]$）；④ 时间响应（分离变量）：$\hat Y^{(1)}(k+1) = \left(X(0)-\frac{b}{a}\right)e^{-a(k)} + \frac{b}{a}$（eq12）；⑤ 逆 AGO 还原：$\hat X(k) = \hat Y^{(1)}(k) - \hat Y^{(1)}(k-1)$。
**适用边界**：数据必须近似单调指数（论文先做 AGO 就是为了构造这个形态）；预测越长越危险——本精读审计发现后段 1.67% 偏离正是"外推越远越不敢保证"的实例。

### eq(17)-(21)：改进熵权 → HIC（p.13-16）
**怎么想到**：12 个社会经济指标要合成一个"人文调整系数"——客观赋权避免拍脑袋。
**完整推导**：极差正规化 $SEF'_{ij}=\frac{SEF_{ij}-\min_j}{\max_j-\min_j}$（eq17）→ 比重 $p_{ij}=\frac{SEF'_{ij}}{\sum_k SEF'_{kj}}$ → 熵值 $E_j=-\frac{1}{\ln n}\sum_i p_{ij}\ln p_{ij}$（eq18）→ 权重 $w_j=\frac{1-E_j}{\sum_k(1-E_k)}$（eq19）→ 加权综合 $SEF''_i=\sum_j w_j SEF'_{ij}$（eq20）→ 线性 g 函数 $H_i=a+b\cdot SEF''_i$（eq21，a、b 用"最小化实际-预测保费差"训练）。
**适用边界**：熵权度量的是**区分度**不是重要性（[评价模块](../02_知识模块/05_评价与决策.html) §1.2 的警告）——组合赋权是标准修正，本论文没做；且见 §4 审计：本表的 w 与 E 数值上不满足 eq19。

**句式库**（原文摘录 + 使用场景，完整版见[模式卡片](01_卡片_2024E_Soochow.html)）：

- 方法引入对比式：`Unlike GWR, which assumes..., MGWR allows...`（先立别人局限）
- 双价值收束：`not only aligns with actuarial principles but also embeds...`（人文+技术）
- 稳健性一句话：`despite changes in..., the trend of... continues to...`（敏感度收尾）

**图表配方**：地理热力（空间分异）→ 双段时序（历史+预测）→ 三情景对照（干预证据）→ 雷达图（多因子区间）→ 消融对照（稳健性）——五张图覆盖 E 类题的完整论证链。
