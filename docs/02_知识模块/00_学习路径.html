原则

  1. 边学边建：知识模块按你需要的顺序上线，写完一篇你学一篇——建站进度 = 备赛进度
  2. 够打就好：12–15 个方法族覆盖六题型，不求百科全书
  3. 每模块四件套：概念讲透 → 最小可复现代码 → 在真题中的用法 → 常见误用
