MMCM/ICM 备赛知识库 02_知识模块

蒙特卡洛与模拟

学习核心模块之一，服务的典型场景：不确定度传播、工期/成本风险、搜索与覆盖、排队与资源占用——一切"随机性是主角"的问题。 验证环境：NumPy 2.5.1，Windows，2026-11-22 全部代码实跑通过。 赛制相关的内容在 03_题型打法，本模块只讲方法本身。

0. 先建地图：模拟的三类用途

用途 问题形态 产出
不确定度传播 输入随机 → 输出分布 分位数、超限概率
系统仿真 过程复杂难解析 资源占用曲线、瓶颈
估计难解积分 高维/复杂区域 数值估计 + 误差棒

心法三句：能解析求解就不要模拟——模拟是最后的手段；模拟的产出是分布不是单个数；每次模拟必带种子与样本量论证。

1. 概念讲透

1.1 随机数、种子与可复现性

现代做法是 NumPy 的 default_rng(seed)：同一个种子重跑，序列逐位相同。论文里报种子不是可选的好习惯，而是可复现性的最低要求——没有种子的模拟结果别人无法验证。多次独立重复用独立流：rng.spawn(n)（或 SeedSequence.spawn()）生成互不重叠的子流，别手工拼凑种子。minit="++"、seed= 这类参数在 03_统计与机器学习 的聚类里同样出现：凡带随机性的算法一律固定种子。马尔可夫链蒙特卡洛（MCMC）属贝叶斯推断的专门话题，本模块不覆盖，知道名字以免混淆即可。

1.2 误差与样本量：1/√n 的暴政

蒙特卡洛估计的标准误差按 $1/\sqrt{n}$ 收敛：样本量 ×100，精度才 ×10（§2.1 实测）。这意味着三位小数的精度需要亿级样本。实战纪律：

  • 先估算需要多少样本：想要 ±ε 的 95% 置信区间，样本量约为 $n \approx (1.96\,\sigma/\varepsilon)^2$——适用条件：σ 事先未知、由小样本试跑（先导批次）估计；目标是均值且样本独立（CLT 近似成立）；比例问题用 $\sigma^2 = p(1-p)$；小样本改用 t 分位数；分位数与极端概率不适用此式（见下条）；
  • 报告必须带误差棒：均值 ± 标准误，或直接给分位数区间；
  • 分位数（P90/P99）比均值需要更多样本——尾部事件天然稀少，工程风险类结论至少十万级样本起步。

1.3 输入分布从哪来：三级来源

模拟的可信度上限由输入分布决定：一级——数据拟合（用观测数据配分布并做拟合优度检验，接 03_统计与机器学习）；二级——三角估算（乐观/最可能/悲观三点，专家给数时的标准格式，rng.triangular 直接可用）；三级——文献取值（注明出处）。任何输入分布的选择都要在假设表里写明来源级别。最忌讳的是"随手正态"：工期、成本类天然偏态，正态会给出不可能的负值与过窄的尾部。

1.4 方差缩减：花小钱办大事

普通抽样浪费在"重复走老路"上。三个常用缩减器：对偶变量（用 $U$ 与 $1-U$ 成对估计，被积函数关于 U 单调时平均方差大降）；分层抽样（按区间分层，每层内部抽样——精确控制覆盖）；重要性抽样（改变抽样分布、按比重加权——尾部概率估计的标准武器）。对偶变量最便宜（一行代码），值得成为默认习惯。

1.5 离散事件仿真：排队的直觉

M/M/1 队的利用率 $\rho = \lambda/\mu$ 决定一切：$\rho \to 1$ 时等待时间爆炸（$\frac{1}{\mu-\lambda}$ 发散）。仿真排队系统时的纪律：预热期丢弃（前段数据受初始空队列影响，不计入统计）；多次独立重复取分布，不只跑一次。资源占用、服务台配置类问题（"加一个窗口值不值"）是它的主场。

2. 最小可复现代码

以下两段 2026-11-22 在 NumPy 2.5.1 实跑通过，输出为真实结果（种子固定，逐位可复现）。

2.1 圆周率估计：误差确实按 1/√n 收敛

import numpy as np
rng = np.random.default_rng(7)
for n in (100, 10000, 1000000):
    p = rng.random((n, 2))
    est = 4 * ((p ** 2).sum(1) <= 1).mean()
    print("n={:>8}  π≈{:.4f}  误差{:.2e}".format(n, est, abs(est - np.pi)))

真实输出：

n=     100  π≈3.0800  误差6.16e-02
n=   10000  π≈3.1620  误差2.04e-02
n= 1000000  π≈3.1437  误差2.10e-03

读法：标准误差按 $1/\sqrt{n}$ 缩小（SE ≈ 1.64/√n），实现误差围绕它波动——三步误差 6.16e-2 → 2.04e-2 → 2.10e-3 展示的就是这个趋势（第一步 ÷3 是运气好，n×100 后误差并不保证 ÷10，保证缩小的是标准误差）。n=1e6 实测印证两位小数稳定；三位小数由该律外推需亿级样本——报告精度位数必须与样本量匹配，n=1 万时 π≈3.162 的"三位小数"是自欺。

2.2 项目工期风险：三角分布 + 分位数

import numpy as np
rng = np.random.default_rng(42)
tasks = np.array([[2, 4, 9], [1, 2, 6], [3, 5, 8]], float)  # 乐观/最可能/悲观（周）
N = 100000
samples = rng.triangular(tasks[:, 0], tasks[:, 1], tasks[:, 2],
                         size=(N, 3)).sum(1)                 # 三任务串行
print("期望工期 =", round(float(samples.mean()), 2), "周")
print("P50 =", round(float(np.percentile(samples, 50)), 2),
      " P90 =", round(float(np.percentile(samples, 90)), 2), "周")
print("超 12 周概率 =", round(float((samples > 12).mean()), 3))

真实输出：

期望工期 = 13.33 周
P50 = 13.25  P90 = 16.12 周
超 12 周概率 = 0.723

读法：三任务的"最可能"相加是 11 周，但模拟给出中位数 13.25 周——串行任务的总工期分布右偏，"最可能值（众数）之和"系统性低估（悲观尾巴更长的任务贡献更大）。P90 = 16.12 周与"超期概率 72%"才是真正的决策信息；均值 13.33 没有偏（均值可加），但它抹掉了分布——均值里看不见 12 周死线下 72% 的超限风险。这就是合并偏置（flaw of averages）：用任何单点（最可能值、均值）做规划都会踩它，Savage《The Flaw of Averages》(2009) 是它的专著出处。

3. 在真题中的用法

题目信息核查于 2026-11-22（来源：COMAP 官网历年题目页）。

真题 场景 模拟范式 三行翻译
2024 MCM B《Searching for Submersibles》（潜水器搜救） 失联观光潜水器位置不确定下的搜救 蒙特卡洛轨迹采样 + 搜索努力分配（接 01_优化方法族） 输入=潜水器位置分布（运动模型 + 采样）；输出=位置分布热图；决策=搜索资源分配
2026 MCM A《Modeling Smartphone Battery Drain》（手机电池放电） 使用模式随机性（屏幕亮度/处理器负载/网络活动的组合，官方题面 2026-11-22 核）→ 放电分布 输入分布传播到放电曲线 输入=使用场景分布；输出=续航分位数；结论=P90 续航与超限风险

共同的骨架：输入分布定来源（§1.3）→ 固定种子跑 N 次（§1.1）→ 报分布不报单点（§1.2）→ 对决策有用的量是分位数与超限概率（§2.2）。凡是题目里出现"不确定""随机""风险""可能"，就要想到模拟是模型链条的收尾环节——确定性模型算出机理，模拟把不确定性灌进去。

4. 常见误用

  1. 不设种子。结果无法复现、无法验证（§1.1）。default_rng(固定值) 是底线。
  2. 样本量与精度位数不匹配。n=1 万报 4 位小数；先按 §1.2 的公式估样本量，再动手。
  3. 输入分布随手正态。工期/成本类偏态量被正态化后，尾部风险被系统性低估。三角/对数正态/经验分布按来源级别选（§1.3）。
  4. 只跑一次就下结论。单次模拟是抽样噪声的一次实现；多次独立重复（不同种子）看结果的散布，或直接报分布。
  5. 把模拟当解析解的替代品。能积分、能解析的问题用蒙特卡洛是负优化（精度更差、速度更慢）——先问解析可不可行。
  6. 忽略输入相关性。"两项任务工期独立"常常是假的（同一批工人），独立假设下的总方差被低估。相关结构要显式建模或声明。
  7. 预热期当统计样本。排队仿真从空队列开始，前段数据严重失真——丢弃预热期再统计（§1.5）。
  8. 尾部事件样本不足。P99 需要的有效样本远多于均值；要么加大样本，要么上重要性抽样/分层（§1.4）。

5. 自检清单

  • 解析可解性先排查过，模拟确有必要
  • 所有随机源固定种子，种子写进论文
  • 输入分布有来源级别声明（数据/三角估算/文献）
  • 样本量按目标精度估算，精度位数与样本量匹配
  • 报告的是分布/分位数/误差棒，不是单点
  • 多次独立重复，结果散布已检查
  • 输入相关性已建模或声明独立假设
  • 排队/时序仿真丢弃了预热期
