微分方程与动力学

学习核心模块之一，服务的典型场景：增长与衰减、振荡、传染、磨损、放电——一切"随时间演化"的机理建模。 验证环境：SciPy 1.18 / NumPy 2.5.1，Windows，2026-11-22 全部代码实跑通过。 赛制相关的内容在 03_题型打法，本模块只讲方法本身。

0. 先建地图：动力学建模四步

步骤 产出 检验方式
① 机理分析 状态变量 + 变化率定律 每一项有物理/经济来源
② 方程 ODE 组 $\dot y = f(t, y)$ 量纲一致、项数最小
③ 求解 数值解（解析是特例） 收敛性 + 守恒量检查
④ 定性分析 平衡点、稳定性、参数依赖 线性化 + 敏感度

心法三句：微分方程模型的质量取决于机理假设而非求解技巧；数值解必须做收敛性检验才可信；稳定性分析常常比数值曲线本身更有说服力。

1. 概念讲透

1.1 从机理到方程：变化率的三个来源

$\dot y = f(t,y)$ 的右端项通常来自三类机理：守恒/平衡（流入−流出，如人口、库存、电池电量）、速率定律（磨损正比于接触功、传热正比于温差）、牛顿力学（$\ddot\theta = -\tfrac{g}{L}\sin\theta$）。以单摆为例（取 $g/L=1$ 无量纲化）：

$$\ddot\theta = -\sin\theta \qquad \Rightarrow \qquad \dot y_0 = y_1,\ \dot y_1 = -\sin y_0$$

写成一阶方程组是给求解器的标准姿势：每个高阶方程拆成状态向量的一层。建模时的自查：状态变量选够了吗（$n$ 阶方程需要 $n$ 个状态）；右端每一项都能指着说"这来自什么机理"吗。

1.2 数值求解：自适应步长与误差控制

欧拉法的直觉是"用当前斜率外推一小步"，误差 $O(h)$；求解器实际用的是 Runge–Kutta 高阶组合，误差 $O(h^p)$。SciPy 的 solve_ivp 默认 RK45（4/5 阶自适应）：误差超阈值自动缩步长，走得顺自动放大。

三个参数决定数值解的可信度：

  • rtol/atol：相对/绝对容差。这是你向求解器承诺的误差预算，默认 1e-3 对论文级结果通常太松，常用 1e-8 量级；
  • max_step：限制最大步长。想要精确的事件时刻（如过零点、周期），不限制步长会错过；
  • t_eval：只在需要的时间点存值，不改变精度；
  • events：事件函数（如"θ=0"），求解器内部自动求根定位过零时刻——比限步长扫点更精确也更省，2026 A 类的"电量降到阈值"时刻正用得上（§2.1 有对照）。

收敛性检验是数值解的成人礼：容差收紧一两个数量级（或换 DOP853 严容差跑参考解）、max_step 减半，重跑后解不变（在需要的位数上）才算数。§4.1 的死法大多源于跳过这一步。

1.3 平衡点与稳定性：比曲线更有说服力的分析

平衡点满足 $\dot y = 0$。其稳定性由线性化判定：在平衡点处展开 $\dot y \approx J\,y$，$J$ 是雅可比矩阵，特征值实部全负 → 渐近稳定（扰动会衰减）；有正实部 → 不稳定；纯虚 → 中心（振荡不衰减）。

二维系统的四类平衡点（按特征值）：

特征值 类型 物理直觉
两负实数 稳定结点 直接滑向平衡
一正一负 鞍点 一个方向稳一个方向逃
共轭复数、实部负 稳定焦点 螺旋收敛（如阻尼摆）
共轭纯虚 中心 无阻尼振荡

上表的边界要记住：共轭纯虚（中心型）是非双曲情形，线性化定理不覆盖——结论可能是中心，也可能是缓慢发散/收敛的螺旋，需用守恒量、相图或数值实验另判（无阻尼单摆 $\theta=0$ 是中心，靠的是能量守恒而非线性化）。另外 $J$ 的元素是逐条偏导：$(J)_{ij} = \partial f_i / \partial y_j$——每个方程对每个状态变量求一次偏导，这是把"机理方程"变成"稳定性判定"的机械步骤。

为什么这比数值曲线有用：稳定性结论对参数小扰动不敏感，而每条数值曲线都依赖初值。论文里一句"平衡点 $(\theta^*,0)$ 处雅可比特征值实部均为负，故该平衡渐近稳定"，比十张不同初值的轨迹图更能证明你对系统有理解。

1.4 刚性：什么时候换求解器

当系统里悬殊的时间尺度共存（一个变量毫秒级衰减、另一个变量小时级演化），显式法（RK45）被迫用极小步长跟着最快尺度走，慢变量部分纯属陪跑——这就是刚性（stiffness）。判据直觉：最快特征值的模远大于你关心的时间跨度倒数。

解法不是缩小问题，而是换隐式求解器：BDF（或 Radau）。§2.3 用同一问题实测：RK45 花 3860 次函数求值，BDF 只要 84 次，差 46 倍。懒得判断刚性时，LSODA 会在两种模式间自动切换。看到求解器莫名慢、步长被压到离谱地小，第一反应查刚性。

1.5 量纲与无量纲化：建模前的减负术

把变量除以特征尺度（$x = L\,\tilde x,\ t = T\,\tilde t$）后，方程里冒出的是无量纲组合数（如 $gL/v^2$）。两个好处：参数从一堆变成两三个，敏感度分析对象明确；时间尺度悬殊的问题无量纲化后刚性程度一目了然。强烈建议：跑数值前先无量纲化，它同时解决刚性问题里的一半和单位混乱里的全部。

2. 最小可复现代码

以下三段 2026-11-22 在 SciPy 1.18 / NumPy 2.5.1 实跑通过，输出为真实结果。

2.1 单摆：数值解 vs 小角近似

import numpy as np
from scipy.integrate import solve_ivp

def pendulum(t, y):
    return [y[1], -np.sin(y[0])]            # θ''=-sinθ（无量纲，弧度制）

sol = solve_ivp(pendulum, [0, 20], [np.radians(60), 0],
                max_step=1e-3, rtol=1e-8, atol=1e-8)
th = sol.y[0]
cross = np.where(np.diff(np.sign(th)) < 0)[0]   # 同向（负向）过零点序列
period = sol.t[cross[1]] - sol.t[cross[0]]      # 相邻两次同向过零 = 一个完整周期
print("初相 60° 实测周期 =", round(period, 3))
print("小角近似 2π =", round(2 * np.pi, 3))

真实输出：

初相 60° 实测周期 = 6.743
小角近似 2π = 6.283

读法：$\sin\theta \approx \theta$ 的线性化只在小角成立；60° 初相下真实周期比 $2\pi$ 长 7.3%。这正是"数值解回答线性化回答不了的问题"的最小案例——只汇报 $2\pi$ 就把模型信息丢在了一阶近似里。周期级定位的标准工具是 events 参数（求解器内部自动求根，配严容差得 6.743001，与解析值 6.743006 只差末位）；本例用 max_step 扫点也可行，但要警惕：默认容差下不设 max_step，扫点测出的周期可偏差到 7.09（约 5%）——自适应算法会在过零点附近"跨大步"。顺手做个守恒体检：无阻尼单摆的能量 $E = 1-\cos\theta + y_1^2/2$ 应全程不变，数值解的能量漂移就是求解器误差的直接读数。

2.2 稳定性：线性化 + 特征值

import numpy as np
J = np.array([[0, 1], [-1, -0.2]])      # 阻尼摆：f=[y1, -0.2y1-y0]，逐项偏导得 J
eig = np.linalg.eigvals(J)
print("特征值 =", np.round(eig, 3).tolist())
print("实部全负 → 渐近稳定" if (eig.real < 0).all() else "不稳定")

真实输出：

特征值 = [(-0.1+0.995j), (-0.1-0.995j)]
实部全负 → 渐近稳定

读法：共轭复根、实部 $-0.1$——稳定焦点，对应"螺旋收敛到平衡"的运动形态（§1.3 表格对照）。阻尼 0.2 越大实部越负、收敛越快；阻尼为零则实部为零，退化为中心（不衰减振荡）。

2.3 刚性：RK45 vs BDF 实测

from scipy.integrate import solve_ivp
f = lambda t, y: [-1000 * (y[0] - 1)]   # 时间尺度 1/1000，问题跨度 2
a = solve_ivp(f, [0, 2], [0], method="RK45")
b = solve_ivp(f, [0, 2], [0], method="BDF")
print("RK45 函数调用 =", a.nfev, "  BDF =", b.nfev)
print("终值 RK45 =", round(float(a.y[0][-1]), 6), " BDF =", round(float(b.y[0][-1]), 6))

真实输出：

RK45 函数调用 = 3860   BDF = 84
终值 RK45 = 0.999917  BDF = 1.0

读法：解 $y(t) = 1 - e^{-1000t}$ 在 $t>0.01$ 后就贴着 1，但 RK45 仍被迫用微步长走完全程（3860 次求值），且精度还被拖累（0.999917 vs 解析值 1.0）；BDF 隐式外推 84 次搞定。同样的现象藏在多尺度模型里：传染模型中"接触秒级、康复天级"、电池模型中"脉冲毫秒、老化小时"，都要想到换 BDF。

4. 常见误用

  1. 数值解不做收敛性检验。容差用默认 1e-3、步长不管，贴出来的六位有效数字全是幻觉。纪律：容差收紧一两个数量级、max_step 减半重跑，解不变才采信。
  2. rtol 单独使用。当解的量级接近 0（如浓度衰减到 1e-9），rtol 失去意义，必须同时设 atol。两者关系：误差预算 ≈ atol + rtol×|y|。
  3. 把小角线性化解当精确解。§2.1 实测 60° 时差 7.3%。凡是 $\sin\theta \approx \theta$、$e^x \approx 1+x$ 类展开，都要声明适用范围，并在范围内用数值解复核。
  4. 多尺度问题硬扛 RK45。求解慢、步长离谱地小，先查刚性换 BDF（§1.4、§2.3），而不是调小容差跟它耗。
  5. 初值与参数不做敏感度分析。动力学模型的初值常常是估的；只画一条轨迹等于把估计误差藏起来。至少做：初值 ±10%、关键参数 ±20% 的扫描。
  6. 守恒量不检查。模型声称能量守恒/质量守恒，就把它作为数值解的体检指标：漂移超过容差说明求解器配置有问题。
  7. 单位与量纲混乱。分钟/小时混用、弧度/角度混用是动力学题两大事故源。无量纲化（§1.5）是根治手段。

5. 自检清单

  • 右端每一项有机理来源，状态变量个数 = 方程阶数
  • 无量纲化完成，参数缩到两三个组合数
  • rtol/atol/max_step 有意识地设置并写进文档
  • 收敛性检验（容差收紧数量级 + 步长减半重跑）
  • 守恒量漂移检查通过
  • 平衡点 + 稳定性分析（线性化特征值）有结论
  • 初值与关键参数敏感度扫描
  • 刚性自查：时间尺度比超过 1e3 时换 BDF/Radau
