模式卡片 schema（每篇 O 论文一张）

{
  "team": "2610917",            // 队伍号（可溯至 Results 册）
  "problem": "2026-D",
  "tiers": {"summary": "",      // Summary 六要素逐槽登记
            "structure": [],    // 章节结构序列
            "models": [],       // 每个模型：类型/假设/验证方式
            "figures": [],      // 每图：论点/类型/自明性评分
            "checks": [],       // 敏感度/收敛/样本外等检验清单
            "wordsmith": []},   // 值得抄的句式
  "distinct": ""                // 这篇 O 独有、同题其他 O 没有的一件事
}

提炼纪律（沿用 upc-archive 73 篇卡片管线的同构标准）：每个字段必须给论文页码/章节锚点，读不出的字段留空不猜；"distinct" 字段必须能与同题其他卡片对照后才允许填写。

升档差值分析方法

对照同题 O vs H/M（各抽 3–5 篇）逐维度比差：假设数量与可追溯性、模型链条层数、检验类型计数（收敛/样本外/敏感度/对账）、图表论点密度、Summary 数字密度。产出是一张"档位差值表"——差值项就是备赛时的升档检查单。方法与 07_写作与SummarySheet 的六要素骨架、03_统计与机器学习 的检验清单互为表里。

为什么不先写内容

拆解页的每个字都要能指回论文原文。在没有 T1 语料时预写"O 奖论文一般做对什么"，写出来的只能是网络二手印象——违反本站"防臆断"纪律（2026 D 题按标题臆断被审查抓出的教训，见仓库内 蓝图.md 第三节验收标准）。订阅入库后，本目录按 schema 逐篇上线，每篇带队伍号与页码锚点。
