2. 打法提炼（网络科学题"从题面走向图模型"的通用路径）

  1. 题面动词→边定义表，图语义写进假设层（p.3-5）：题面 "create a network for the ball passing" 翻译成"节点=球员、边=传球事件、权=传球次数 w_ij"只用半页（p.4-5），而方向性选择（无向 w_ij=w_ji）写进假设第 1 条（p.3）。网络题开局 2 小时的产出就是这张定义表+方向性声明——图的语义选择本身就是建模，与 04_图论与网络（../02_知识模块/04_图论与网络.html） §1.1 心法一致。
  2. 参数组全给定义式 + 足球语义翻译（p.5-6）：L/ρ/D/加权聚类系数逐个给公式（eq2-7），每个参数后接一句领域解读（"degree 高=更多参与进攻"、"小直径=传球分散"）。多指标互证 + 语义翻译，是 04 模块 §1.4"多指标互证不单报"的 O 级执行。
  3. 结构发现三段式：目视→算法→定量复核（p.7-8）：拓扑距离矩阵热图目视找小值（Fig2 p.7）→ K-means 正式聚类并画回场地（Fig3 p.8）→ 用 227 传/26.7%、簇内 C=7.31 vs 全队 7.62 复核簇的紧密度。三段式让聚类从黑箱变成可验证的发现。
  4. 题面每个状语对应一节一图（p.3, 8-10）：题面 "explore multiple scales such as regions and time" 被拆成时间尺度（10-min/整场/整季，Fig4-5）与区域尺度（8 区域热图，Fig6）两节——题面任务清单逐项对账，每项有公式、有图、有结论，交付物一个不漏。
  5. 图统计量直升指标体系骨架（p.11-12）：Task 1 的聚类系数 C 直接升格为 Task 2 的 coordination 指标 γ；非图量（进球率/防守率/坐标统计量）补成静态/动态两层。指标体系从网络模型里"长"出来而非另起炉灶——这是网络题从 Task 1 走向 Task 2 的最短路径。
  6. 把约束写进搜索可行域，再给方法起专名（p.13-15, 24-27）：两队赛果（胜/负/平）变成权重搜索硬约束，在可行域里取得分方差最小的一组；整套流程命名 "Adversarial Regression + LowestError" 并在摘要-正文-代码三处一致。自定义方法的命名记忆点 + 五步流程框，是可复用的写作动作。
  7. 敏感度瞄准"人为设定的自由参数"（p.21-22）：两个敏感度都不是常规权重扰动，而是模型里两个"拍脑袋"参数——平局判定阈值 ε 和 tempo 的 N-pass 球数。对自由参数扫描直接回应"结论是不是参数巧合"，比泛泛扰动更让评委信服。
  8. 建议层三件套：数字表+对标图+战术板（p.16-19）：每条建议有支撑——阵型适配数字表（Table 3 p.16）、强队对标条形图（Fig 11 p.17，自补 Italy 2012 欧洲杯数据并引文献[7]）、战术板示意图（Fig 12 p.18）。"官方数据不够就自补外部对标数据"与 2024 E 卡（01_卡片_2024E_Soochow.html） 打法 2 同构，跨年代稳定。
