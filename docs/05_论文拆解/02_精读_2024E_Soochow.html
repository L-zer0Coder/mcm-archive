1. 逐节导读

Summary（p.1）

  • 【它写了什么】问题一句化 → 方法链条一句化（MGWR+熵权+GM(1,1)）→ 结果带四位数（加州 $20.1394M→$31.0054M）→ 结论一句。
  • 【为什么这样写】评委 5 分钟内要看到"跑过真数据"的证据，四位小数的数字是最便宜的证明。
  • 【你要学什么】数字锚点法：摘要里每个结论句都挂一个可回查到正文表格的数字。

§1 Introduction + §2-3 Preparation（p.3-6）

  • 【它写了什么】背景、题面重述、Related Work（GWR→MGWR 文献脉络）、Our Work 路线图；假设只有 3 条（空间异质性、社会经济因子相关性、成本线性）。
  • 【为什么这样写】假设少而每条直接喂给后面的模型（假设 2 → MGWR 存在的意义；假设 3 → 熵权 HIC 存在的意义）——假设表是模型的地基，不是仪式。
  • 【你要学什么】"假设-模型"配对法：写每条假设时自问"它支撑哪一段模型"，对不上号的假设删掉。

§4 Insurance Strategy Model（p.6-13，Q1 主战场）

  • 【它写了什么】数据三源（ERA5-Land 96 变量、Global Disaster Data Platform、NAIC）→ PCA 降维 96→4（p.7, eq2）→ 样条插值补事件坐标的气候值（eq3, p.8）→ 阈值判别补漏记极端事件（eq4, p.8）→ MGWR 回归赔付（eq5-6, p.8-9）→ 定价公式（eq7-9, p.9）→ GM(1,1) 外推（eq11-12, p.10）→ 历史可视化与三风险区策略（p.11-13）。
  • 【为什么这样写】每个数据缺口都有对应的数学动作：格点对不上坐标→插值；官方漏记极端事件→阈值判别。方法是"补数据"的仆人，不是炫技。
  • 【你要学什么】数据源三件套并给脚注 URL（p.7）——O 队与普通队的常见分野就在"数据不够时去哪找、怎么标注"。

§5 Community Building（p.13-18，Q2）

  • 【它写了什么】MGWR 加保护因子 P_i（eq13, p.12）→ 损失最小化 min L=Σ(D_i+λC_i)（eq16, p.13）→ scipy 求解北美（p.16）→ 熵权 HIC 权重表（Table 4, p.14）→ 三情景对照（Fig 6, p.18）。
  • 【为什么这样写】Q2 的"策略"被拆成两个可计算主体：社区管理员（优化 eq13-16）与业主（熵权 g 函数 eq17-21）——题面的"谁该做什么"被翻译成两个数学对象。
  • 【你要学什么】人文维度参数化：把"社区关怀"写成 g 函数与权重表（healthcare 0.375/GDP 0.250/密度 0.250/教育 0.125），而不是口号。

§6 Historical Landmarks（p.19-21，Q3）

  • 【它写了什么】MGWR 第三次改写：因变量换成"所需保护等级"，自变量换成建筑因子（eq22, p.19）→ 自由女神像系数区间解读 + 雷达图（Fig 8, p.21）→ 致社区完整信件（p.24，含 $2.5M 预算）。
  • 【为什么这样写】题面点名要 letter，论文给的是带预算明细的正式交付物——题面点名的交付物一个都不能少。
  • 【你要学什么】同构模型改写手法：换因变量+换自变量集合=新模型，方法叙述只写增量。

§7-9 + 附录（p.21-25）

  • 【它写了什么】敏感度只做熵权消融（承认超参少，p.21-22）→ 优缺点 → 结论 → Letter → AI Utilization Report（p.25，声明 ChatGPT 用于插图与润色）。
  • 【为什么这样写】检验"小成本大覆盖"；AI 披露合规（完整三要素见官方政策）。
  • 【你要学什么】O 论文的检验可以少，但必须存在且单独成章；AI 披露不是选装件。

n = len(x)
ago = np.cumsum(x)                                   # Y(1)(i) = sum X*(k), eq(11) 上式
z = (ago[:-1] + ago[1:]) / 2.0                       # 背景值（紧邻均值）

3. 公式逐条精讲

eq(5)-(6)：MGWR 主模型（p.8-9）

怎么想到：赔付既受气候影响又有空间异质性（西部旱、东南涝——Fig 2），普通 OLS 只能给全国一个系数，抹掉了地理差异。 完整推导：GWR 的一般式 $y_i = \beta_0(u_i,v_i) + \sum_k \beta_k(u_i,v_i)X_{ik} + \epsilon_i$（eq5）——每个位置 $(u_i,v_i)$ 用它周边样本拟合自己的系数，权重随距离衰减（高斯核：$w_{ij}=\exp(-d_{ij}^2/b^2)$，带宽 $b$ 控制邻域大小）。MGWR 的增量（eq6 的应用形态）：$\mathcal{I}_i = \beta_0(u_i,v_i) + \sum_{k=1}^{4}\beta_k(u_i,v_i)\,PCA^{k}_{Factor} + \beta_5(u_i,v_i)\,\mathcal{P}_i + \epsilon_i$——论文比 GWR 多说的一句话是"每个协变量各自有带宽"：气候因子的影响尺度可能与人口密度不同，硬用同一个带宽会把快变量抹平。带idge估计：对每个 $\beta_k$ 独立做带宽搜索（论文未述核函数与搜索细节——这是它"无诊断表"缺项的来源之一）。 适用边界：需要足够密的空间样本；外推到样本稀疏区（如 Q3 单个地标）时，MGWR 退化为"系数区间解读"（p.20-21 的区间表述正是承认了这一点）。

eq(7)-(9)：定价链（p.9）

怎么想到：题面要"既人道又盈利"的定价——把两个价值各参数化，再乘法合成。 完整推导：人文系数 $H_i = g(SEF_i)$（eq7，g 由熵权综合指数线性化而来，见 eq21）；盈利因子 $P = HPR + TPM$（eq8，历史赔付率+目标利润率）；最终 $FP_i = BP \times (1+\theta\,RS_i) \times H_i \times P$（eq9）——风险分 $RS_i$ 抬价、人文系数 $H_i$ 让利、盈利因子兜底。 适用边界：乘法合成意味着任何一项趋零则保费趋零——$H_i$ 必须有下界（论文未讨论，普通队补一个 clamp 是低成本加分）。

eq(11)-(12)：GM(1,1)（p.10）

怎么想到：只有 11 个年度点、且要外推 11 年——样本量不允许 ARIMA，灰色模型专为"少数据、指数型趋势"设计。 完整推导：① AGO 平滑：$Y^{(1)}(i)=\sum_{k=1}^{i}X^{*}(k)$——累加把震荡抹成近似指数曲线；② 灰色微分方程 $\frac{dY^{(1)}}{dt} + aY^{(1)} = b$；③ 离散化最小二乘：对 $k=2..n$ 用背景值 $z(k)=\frac{1}{2}(Y^{(1)}(k)+Y^{(1)}(k-1))$ 代替导数点，得矩阵形式 $[a,b]^T=(B^TB)^{-1}B^TY_N$（eq11，$B$ 的每行 $[-z(k), 1]$）；④ 时间响应（分离变量）：$\hat Y^{(1)}(k+1) = \left(X(0)-\frac{b}{a}\right)e^{-a(k)} + \frac{b}{a}$（eq12）；⑤ 逆 AGO 还原：$\hat X(k) = \hat Y^{(1)}(k) - \hat Y^{(1)}(k-1)$。 适用边界：数据必须近似单调指数（论文先做 AGO 就是为了构造这个形态）；预测越长越危险——本精读审计发现后段 1.67% 偏离正是"外推越远越不敢保证"的实例。

eq(17)-(21)：改进熵权 → HIC（p.13-16）

怎么想到：12 个社会经济指标要合成一个"人文调整系数"——客观赋权避免拍脑袋。 完整推导：极差正规化 $SEF'_{ij}=\frac{SEF_{ij}-\min_j}{\max_j-\min_j}$（eq17）→ 比重 $p_{ij}=\frac{SEF'_{ij}}{\sum_k SEF'_{kj}}$ → 熵值 $E_j=-\frac{1}{\ln n}\sum_i p_{ij}\ln p_{ij}$（eq18）→ 权重 $w_j=\frac{1-E_j}{\sum_k(1-E_k)}$（eq19）→ 加权综合 $SEF''_i=\sum_j w_j SEF'_{ij}$（eq20）→ 线性 g 函数 $H_i=a+b\cdot SEF''_i$（eq21，a、b 用"最小化实际-预测保费差"训练）。 适用边界：熵权度量的是区分度不是重要性（评价模块（../02_知识模块/05_评价与决策.html） §1.2 的警告）——组合赋权是标准修正，本论文没做；且见 §4 审计：本表的 w 与 E 数值上不满足 eq19。

5. 从本篇提炼的可复用模板

论文结构模板（代码块形式，直接抄）：

Summary（六要素，数字锚点法）
1 Introduction：背景 / 题面重述 / Related Work（文献脉络对比式引入）/ Our Work 路线图
2 Assumptions（3-5 条，每条标注支撑哪段模型）+ Notations
4 主模型（Q1）：数据三源+脚注URL -> 预处理全公式化 -> 主回归 -> 应用公式 -> 求解与可视化
5 扩展（Q2）：主模型"加法改写"+ 优化目标 + 求解
6 再扩展（Q3）：改因变量/自变量 + 案例解读
7 Sensitivity（单独成章，小成本大覆盖）
8 S&W + 9 Conclusion
Letter/交付物（题面点名的一定有）+ References + AI Report（完整三要素）
