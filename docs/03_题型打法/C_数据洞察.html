C 题 · 数据洞察型打法

MCM C 题：数据洞察——真实数据集的清洗、探索、建模、预测。方法深度见 03_统计与机器学习 与 07_写作与SummarySheet；本页是题型层的选型与打法。 真题事实核查日期 2026-11-22（来源：COMAP 官方题面 PDF）。

方法族映射：选型决策

你面对的子问题 首选 依据模块
数据到手第一件事 清洗流水线 + 留账 03_统计与机器学习 §1.1
变量关系探索 EDA 三件套（分布/相关/时序） 03 模块 §1.2

结论落地成建议 评价法排序 + 写作纪律 05_评价与决策、07_写作与SummarySheet

决策主线：清洗 → EDA → 简单模型起步 → 样本外检验 → 复杂化只在简单模型失败后。C 题的"势头"类问题（2024 C）本质是检验一个概念是否可量化、是否有统计显著性——先想"怎么定义、怎么检验"，再想"用什么模型"。

打法骨架

  1. 开题 2h：数据字典逐列过一遍；把题目问题逐条编号（后面逐条对应答案）
  2. 清洗 6h：缺失/异常/口径/重复四类处理，每步留账（步骤/理由/影响行数）
  3. EDA 6h：三件套图 + 数据质量备注；这一步的产出直接进论文
  4. 建模 12h：训练/验证/测试三分，测试集只在最终用一次；每个结论 p 值 + 效应量 + 图
  5. 逐题作答 10h：题目问题编号 ↔ 论文小节一一映射，问什么答什么
  6. 写作贯穿：清洗附录 + 每图一论点；数字前后一致对账

本题型 O 卡示例：2022 C O 卡（SCUT，INFORMS 奖）（../05_论文拆解/17_卡片_2022C_SCUT.html）

常见死法

  1. $R^2$ 崇拜——训练集拟合好≠能预测（03 模块 §2.1 的 5 样本教训）
  2. 测试集泄漏（看一眼改一次模型）；时序数据用未来信息填充
  3. 相关当因果（2024 C 的 momentum 是"是否可量化、是否显著"，不是"是否导致胜利"）
  4. 异常值静默删除——极端点往往是题目的趣味所在，保留并讨论
  5. 清洗不留账——"我们做了一些处理"等于没说
  6. 黑箱堆模型：小样本上深度学习毫无意义，简单模型 + 置信区间说话
