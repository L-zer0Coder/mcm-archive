B 题 · 离散型打法

MCM B 题：离散类——优化、调度、物流、组合。方法深度见 01_优化方法族 与 04_图论与网络；本页是题型层的选型与打法。 真题事实核查日期 2026-11-22（来源：COMAP 官方题面 PDF）。

题型画像：近三年 B 题考了什么

年份 题目 离散范式
2026 《Creating a Moon Colony Using a Space Elevator System》太空电梯月球殖民 地月运输系统下的访问/建设场景（物流与运营规划）

三年画像："在一堆约束下把有限资源安排好"——变量天然带整数/选/不选性质。注意 B 题常有连续内核（流量、概率），典型解法是 MILP 或"模拟产生分布 + 优化做决策"的混合（2024 B 即模拟采样 × 努力分配）。

方法族映射：选型决策

你面对的子问题 首选 依据模块

决策主线：三行翻译（变量/目标/约束）→ 先跑通最小精确模型 → 规模大了再谈启发式 → 每个解报 gap。离散题最值钱的一句话是"我的解离最优最多差多少"（gap 界）。

打法骨架

  1. 开题 2h：把题面翻译成三行表 + 变量类型表（哪些 0-1、哪些整数、哪些连续）
  2. 最小模型 6h：砍掉次要约束先跑通（一个可行最优解 > 完整模型的报错墙）
  3. 逐条加约束 10h：每加一条重跑一次、看目标值变化——出 infeasible 立刻定位（01 模块 §4.1 三步排查）
  4. 规模处理 10h：超时则对称破缺、聚合、启发式 + 界对照
  5. 场景与敏感度 8h：关键参数扫描；不确定输入用蒙特卡洛出分布
  6. 写作贯穿：模型公式先于代码出现；gap 与运行时间进结果表

本题型 O 卡示例：2023 B O 卡（Tsinghua）+ F 档对照卡（Fuzhou）

常见死法

  1. 0-1 变量对称性爆炸（20 个相同设备互换 → 分支定界搜排列；01 模块 §4.2）
  2. big-M 无脑 1e6（松弛无区分度，01 模块 §4.3）
  3. 启发式裸报不附界（§1.4 的教训：说服力只有一半）
  4. infeasible 摊手不排查（先让"显然可行"解过一遍约束）
  5. 需求/位置当确定值——题目说"可能""估计"就要上分布
