三梯队定义

梯队 内容 官方获取 状态
T1 O/F 奖完整论文 mathmodels.org 会员资源（$35/年 电子订阅，登录后按题目条目下载；2026 各题 3–19 篇不等） 待订阅入库，SOP 见下
T2 H/M 奖论文（升档差值的"对照组"） 同 T1 渠道，题目条目内含获奖级别标注 同上

T0 官方免费层：题面 + Results 全册 免费——题面 PDF 与 Results 册（全参赛队名录+奖项分布）在 contest.comap.com 结果页直接下载 已入库 ✓

获取路由结论（2026-11-22 核）：COMAP 的完整获奖论文与评述在会员墙内（$35/年，参赛队均摊极低）；免费层可完整获取题面与全量参赛统计。本站先把免费层用透（题面事实库 ✓、奖项分布 ✓），订阅后按 SOP 补 T1–T3。

已入库清单

  • 题面 18 份（2024–2026 三年 × 六题）：见 01_COMAP官方 各题型页引用，2026-11-22 全部从官方 PDF 核实
  • Results 全册 18 份（2024–2026 三年 × 六题，约 7,600 页）：04_语料库/官方结果册/ 目录（左栏树可跳转 PDF）——每册含全参赛队名录（机构/队伍号/奖项等级）

T1/T2/T3 入库 SOP（订阅后执行）

  1. mathmodels.org 登录 → 会员资源 → 对应题目条目 → 下载学生论文 PDF 与 Commentary PDF
  2. 存入 04_语料库/T1_O奖论文/<年份>_<题字母>/（命名 <队伍号>_<国家>_<奖>.pdf）
  3. 运行 _builder/ 的拆解管线（建中）：按 73 篇模式卡片同构方法生成结构卡片 → 05_论文拆解/
  4. 语料页更新入库清单与核查日期

语料使用纪律

  • 逐字可溯：所有从语料提炼的结论要能指回原始 PDF 的页码/队伍号
  • 奖级口径：以官方册子与会员页的 designation 为准（Outstanding Winner / Finalist / Meritorious / Honorable Mention / Successful Participant）
  • 防臆断：论文没读过的内容不进拆解页——本站 2026-11-22 的拆解页仅覆盖已入库语料
